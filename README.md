# AMSP — Eureka! 2026 Prototype

AI-assisted antimicrobial stewardship prototype for hospital stewardship teams.

## Demo status
This is a front-end prototype using synthetic data. It is not a clinical system, medical device, prescribing tool, or validated clinical decision-support system. Do not connect it to real patient data.

## Planned reference frameworks
ICMR Antimicrobial Stewardship Program guidance; relevant ICMR antimicrobial/AMR guidance; WHO AWaRe; India's DPDP framework and ABDM principles; HL7 FHIR; ISO 14971; IEC 62304; IEC 81001-5-1; ISO 13485 where applicable; FDA CDS guidance for future U.S. deployment; EU MDR/MDCG software guidance for future EU deployment.

Formal applicability, certification, regulatory status, clinical validation, and compliance must be assessed before real-world clinical deployment.
